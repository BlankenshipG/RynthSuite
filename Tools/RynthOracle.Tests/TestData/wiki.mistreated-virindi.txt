== Overview ==
Quest to upgrade Imbued Asteliary items from the old retail quest [[Simulacra Infiltrators]].

== Walkthrough & Notes ==
# Talk to [[Mistreated Virindi]] in [[Zaikhal]] to start the quest.
#* {{stamped|Sneaky_Virindi}}
# Run to the [[Hidden Infiltrator Keep]] dungeon at 28.5S, 90.9W (layout is a clone of [[Northern Infiltrator Keep]]).
#* Run from [[Mount Lethe]] or [[Ayan Baqur]]. Dungeon is tieable/recallable if you die.
# Inside the dungeon, kill [[Tortured Ravener]]s and [[Damaged Doll]]s for a {{Itemlink|Shiny Red Stone}}.
#* {{stamped|Shiny_Red_Stone_Found}}
# Head to the end of the dungeon, where Guardian of the Asteliary is guarded by Alarming and Dark Simulacrum. He drops several {{Itemlink|Guardian of the Asteliary's Message Shard}} for QB.
#* {{stamped|Guardian_of_the_Asteliary_Message_Shard}}
# Head through the portal to the next dungeon, Asteliary Contentment.
#* From this point forward, if you die you'll have to run through the first dungeon again.
# Proceed through this linear dungeon to the end and take the portal to the final dungeon, Asteliary Pique.
#* In this dungeon you'll find Asteliary Counselors and Dark Simulacrum. Be careful of the Dark Simulacrum missile attacks, as they hit hard.
# Inside Asteliary Pique, kill [[The Architect]] and loot {{Itemlink|Vial of The Architect's Blood}}.
#* {{stamped|Powerful_Blood_Obtained}}
# Return the {{Itemlink|Vial of The Architect's Blood}} to the Mistreated Virindi in Zaikhal for 80 Enlightened Coins and a Hero Token.
#* {{stamped|Blind_Revenge}}
# Return the {{Itemlink|Shiny Red Stone}} to Ellie in Crater for 30 Enlightened Coins and 5 Mythical Keys.
#* {{stamped|Shiny_Red_Stone_Turnin}}
# Instead of turning in the {{Itemlink|Vial of The Architect's Blood}} to the Mistreated Virindi, you can upgrade an {{Itemlink|Imbued Helm of the Simulacra}}, {{Itemlink|Imbued Shield of the Simulacra}}, or {{Itemlink|Imbued Asteliary Orb}} to upgrade those items.
