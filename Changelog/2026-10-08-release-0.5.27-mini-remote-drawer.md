# RynthAi 0.5.27-legacy-ui: Mini Remote in the RynthAi dashboard

Released 2026-10-08. Previous release: 0.5.26-legacy-ui (T11 item state).
Needs RynthCore 2026.10.5.21 or later for the drawer. Older engines never call the
new export, and the floating Mini Remote works as before.

## What's new

- **The Mini Remote draws inside the engine's RynthAi dashboard**, in its new Mini
  Remote drawer (right-click Hub, or the drawer tab). It has every section:
  - session rates, Reset XP and Report
  - the attack target and summon bars, with the summon's time left
  - the item slots, with drag and drop
  - toggles, bank, rebuff, Translate and the Guardian answer
- **Options menu in the drawer.** It has the same section switches, ILT Hub windows
  and horizontal layout as the floating window. Lock position and Hide don't apply
  there, so they are replaced by **Floating window too** (also shows the floating
  Mini Remote) and Inventory HUDs setup.
- Pack counts, the slot selection and the target / summon polling run while the
  remote shows in the drawer or the floating window (`HudController.MiniRemoteActive`).
  The same signal keeps the ILT Hub's bank and gear data fresh.

## Plugin API

- New export `RynthPluginRenderEmbed(const char* surface, float width, float height, float* wantWidth, float* wantHeight)`.
  - Surface `"miniremote"` draws the Mini Remote into the engine's current ImGui
    window.
  - It reports the width of its column layout and the height drawn.
  - Returns 0 before login, before the HUDs exist, or for an unknown surface.

## Files

- `PluginExports.cs`: `RynthPluginRenderEmbed`.
- `RynthAiPlugin.LocalFeatures.cs`: `RenderEmbeddedMiniRemote`. The ILT Hub's
  "Mini Remote visible" now counts the drawer.
- `Huds/HudController.cs`: `MiniRemoteActive`, `RenderEmbedded`.
- `Huds/MiniRemoteHud.cs`: `RenderEmbedded`, `EmbeddedWidth`, and the Options menu's
  drawer variant.
- `RynthAiVersionCommand.cs`: 0.5.27-legacy-ui.
