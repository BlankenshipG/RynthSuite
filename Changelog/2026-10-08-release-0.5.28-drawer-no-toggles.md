# RynthAi 0.5.28-legacy-ui - 2026-10-08

Previous release: 0.5.27-legacy-ui.

## Changed

- **Mini Remote drawer without the Toggles section.** The RynthAi dashboard drawer no longer
  shows the Macro / Combat / Buff / Nav / Loot / Meta / Pet checkboxes: the dashboard it sits on
  has the same switches. The floating Mini Remote window (`/ra remote`) keeps them, and its
  Options menu still turns them on or off.
- In the drawer's Options menu the "Toggles" entry is hidden, since it only affects the
  floating window. In the horizontal layout the drawer drops the actions column when item slots
  are off too, and sizes itself without it.

## Files

- `Huds/MiniRemoteHud.cs`: `_embedded` (set only inside `RenderEmbedded`), `ShowToggles`,
  used by the section, column and width checks; `EmbeddedWidth` is now an instance method.
- `RynthAiVersionCommand.cs`: 0.5.27 -> 0.5.28-legacy-ui.

## Checks

- `dotnet build -c Release` (RynthAi) succeeds.
