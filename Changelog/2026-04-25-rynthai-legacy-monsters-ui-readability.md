# Changelog — RynthAi legacy “Monsters” in-game panel (readability) (2026-04-25)

- **RynthCore.Plugin.RynthAi** **0.6.5**
- Wider default window, **resizable** table, **3-letter** toggle column headers (Fst, Brd, …) instead of single letters.
- **Help “?”** popup with full names for curses and attack toggles, plus E/Del notes.
- One **hint line** under the toolbar (curses vs attacks) and a short note on the add row.
- Combos: **darker, flatter** frame colors, normal **dropdown arrows** (removed `NoArrowButton`) for clearer affordance; slightly larger **toggle** dots; column widths tuned for `Damage`, `ExVuln`, `Ammo`, `Prio`, `Expr`.
