# RynthAi 0.5.105 — Trade Shop from Inventory

## Inventory Storefront

The Inventory panel header (Modern and Classic) now has a Storefront icon that opens the Trade Shop editor (`/ra tradeshop ui`). Prices and bank conversion rates live in that window — not buried under Advanced → Vendoring.

## Where to set prices and rates

1. Click the Storefront icon on Inventory (or run `/ra tradeshop ui`).
2. **Payment / bank conversion rates (UB-IT)** — pyreals per MMD, EC buy rates (MMD/Lum/LK/MK/WEC), and which currencies to accept.
3. **Catalog** — enable listings and edit each item’s price in pyreals (alt currencies shown from the rates table).

Advanced Settings → Vendoring still has an “Open Trade Shop window” shortcut.
