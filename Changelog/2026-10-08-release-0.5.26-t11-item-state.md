# RynthAi 0.5.26-legacy-ui - New ACECustom T11 item state for item ID and loot

**Date:** 2026-10-08
**Previous release:** 0.5.24-legacy-ui (0.5.25 is reserved by the Enlightenment sigil-chain work, not yet released)
**Branch:** `main`
**Pairs with:** RynthCore engine 2026.10.5.20 (Add-to-loot tooltip text only; the new loot keys reach
any engine through the editor vocabulary)

## Why

ACECustom's endgame updates (#539, #543, #544, 2026-09-29 to 2026-10-07) changed what a T11 item tells
the client:

- Three T11 properties are now sent in the appraisal as real values (`[AssessmentProperty]`):
  `WeaponAugScaleQuality` (int 9060, the weapon's 0-1000 quality roll), `WeaponAugScaleTier` (int 9061)
  and `ZcTier` (int 50109, the loot tier a Zone Control piece was stamped at).
- Armor, jewelry, clothing and cloaks gained a **Gear Grade** line ("- Gear Grade: B+ (average of 4
  rolled lines)"), every T11 piece a **Properties** slot count ("- Properties: 3 of 5"), and a
  **Tainted** line once a bag stops working on it.
- Modifier lines gained markers: "(Built-in)", "(Locked)", "(+N tinkered)", "(off here)".
- Jewelry got its own **Cast on Strike** modifier (catalog key 54): "Cast on Strike 75% power [50-100]
  - Force Arc, 13% per hit".

RynthAi knew none of this. Worse, the new lines broke the old parser: Gear Grade, Properties and
Tainted sit inside the "Modifiers:" block, so each was counted as a fake modifier (inflating
"T11: Modifier Count"), and the markers after a line's "[min-max]" band hid the band, so roll % read -1.

## What changed

### LootSdk (shared by RynthAi and the editor)

- `T11ItemInfo` reads Gear Grade (label, rank, line count), Properties (used, limit, free) and Tainted,
  both in the Modifiers block and in a weapon's Property Details. They are no longer modifiers.
- Modifier lines: the band is found anywhere on the line; "(Built-in)", "(Locked)" and "(+N tinkered)"
  are read into `T11Modifier.BuiltIn / Locked / Tinkered`; the jewelry proc's spell and chance join
  `Procs` (so "T11: Cast on Strike Count" counts it).
- `T11Catalog`: modifier 54 "Cast on Strike" (jewelry) added; constants for 9060 / 9061 / 50109.
- New `T11ServerProps` (ZcTier, WeaponTier, WeaponQuality) passed to `T11ItemInfo.Parse`. A stamped tier
  of 11+ marks an item T11 even without the "T11 - " name prefix. `Tier` is the stamped tier when sent,
  else the old wield-gate estimate; `TierIsExact` says which.
- New loot keys (RynthAi virtual keys):

  | Key | Value |
  |-----|-------|
  | T11: Tier | stamped tier when sent, else the estimate (was "T11: Tier (est.)", same id) |
  | T11: Tier Is Exact | 1 stamped, 0 estimated |
  | T11: Gear Grade | S = 16 ... F- = 1 (the editor shows the letters) |
  | T11: Property Slots Used / Property Slot Limit / Free Property Slots | from "Properties: N of M" |
  | T11: Tainted | 1 when bags no longer work on it |
  | T11 Mod: Cast on Strike | the jewelry proc's power % |

- The editor's long-key list names the real properties `WeaponAugScaleQuality`, `WeaponAugScaleTier`
  and `ZcTier` (VTank can read these too; they were "key 9060" etc. before).
- **Add to loot profile** with "Include T11 attributes" now requires at least this item's stamped
  tier and Gear Grade, and the jewelry Cast on Strike power instead of noting it as unknown. Property
  slots and Tainted are left out (bag state, not quality).

### RynthAi

- `T11ItemSupport` reads 50109 / 9061 / 9060 from the object and re-parses when they change; the
  stripped wield-gate / rating fallback also covers T11-stamped items without the name prefix.
- **Item info** (Mag-style ID line): new field "T11 tier / grade / slots", on by default:
  "T16" (or "~T16" when estimated), "Quality 873", "Gear B+ (4 lines)", "Props 3/5", "Tainted".
  Modifier list shows "(+20 tink)" and "(Locked)". Hide it with `/ra iteminfo field t11` or the
  Item Info settings window.
- `/ra t11 item` prints the exact or estimated tier, quality, gear grade, property slots, Tainted and
  each modifier's markers.
