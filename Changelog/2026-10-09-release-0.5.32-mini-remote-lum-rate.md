# RynthAi 0.5.32-legacy-ui - 2026-10-09

Previous release: 0.5.31-legacy-ui.

## Fixed

- **Mini Remote / ILT Hub session rates: Lum/h showed 0** while the bank's luminance was
  climbing (Silentkelpie: about 5b banked in a few minutes, Lum/h 0).
  - Cause: the rate only counted "You've banked N Luminance" chat lines. ACECustom prints that
    line only for the killer's own Kill and Quest luminance. Luminance shared by a fellowship or
    a Zone Share area (`XpType.Fellowship`) is banked with no chat line, so a character whose
    lum comes from shares saw nothing.
  - Fix: the session total now follows the bank's luminance property
    (`PropertyInt64.BankedLuminance`, 9005). ACECustom sends it to the client with every XP
    batch, so it covers kill, quest and shared luminance alike. Rises between 5-second samples
    count as income. Drops (aug / enlightenment spending, transfers out) are ignored, and the
    next rise still counts.
  - The chat line is now only a fallback, counted until the property is first seen (a server
    that doesn't send it), so lum is never counted twice.

## Known, not fixed here

- **Kills/h stays 0 when a combat pet lands the killing blows.** Kills are counted from the
  server's killer notification, and ACECustom (`Creature_Death.GetDeathMessage`) sent that
  only when a player lands the last hit; a pet kill told the owner nothing the client can see.
  The server side is fixed in ACECustom (`Changelog/2026-10-09-pet-kill-notification.md`: the
  owner now gets the notification for their pet's kills). No RynthAi change is needed; pet
  kills count once that server build is running.
- Coins/h counts only Enlightened Coin gains (carried, or the bank's coin balance on a bank
  refresh); 0 is correct when nothing is earning coins.
