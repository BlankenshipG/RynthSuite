# Release notes — RynthBundle **0.4.1** (suite components) (2026-04-22)

This file documents the **RynthSuite** pieces that ship inside **RynthBundle-Setup.exe** **0.4.1**, built from the **RynthCore** installer pipeline (`Build-Release-All.ps1` with `-Version 0.4.1`).

## Included from this repo

- **Plugins:** all `Plugins\RynthCore.Plugin.*` projects (published NativeAOT x86 into the bundle `Runtime\Plugins\` and RynthAi mirror under `Suite\RynthAi\`).
- **Tools:** `RynthCore.LootEditor`, `RynthCore.MonsterEditor` (self-contained x64 under bundle `Tools\`).

## Dependency / security

- Explicit **Tmds.DBus.Protocol** **0.21.3** on Avalonia-based tools (see `Changelog/2026-04-22-tmds-dbus-protocol-security.md`).
