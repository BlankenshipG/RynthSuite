# Mini Remote Options opens RynthAi Settings

Date: 2026-10-16
Plugin: RynthCore.Plugin.RynthAi 0.5.75-legacy-ui (previous 0.5.74-legacy-ui)

## Change

The Mini Remote **Options** button opens RynthAi Settings (`/rc ui open Settings`) instead of only the Mini Remote section popup.

- Left-click: RynthAi Settings (Advanced Settings panel).
- Right-click: previous Mini Remote sections / layout / slot size popup.
