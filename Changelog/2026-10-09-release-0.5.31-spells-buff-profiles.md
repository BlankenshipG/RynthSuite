# RynthAi 0.5.31-legacy-ui - 2026-10-09

Previous release: 0.5.30-legacy-ui.

## Added

- **Spells window** (`/ra spells`, or the sparkle button on the Loaded Files "Buffs:" row, or
  Settings > Buffing > Buff Profiles). It is modelled on ub-IT's spell book buff tab and lists
  every spell in ACECustom's spell catalog (6,266 spells):
  - search by name or spell family;
  - filter by school (Creature, Life, Item, War, Void), by level 1-8, by target (Self, Other,
    Item, Fellowship), by effect (Buff by default) and "Known only" (your spellbook);
  - sortable columns: Name, School, Level, Target, Effect, Family (hidden by default) and Known.
    Click a header to sort; Shift+click adds a second sort (the default is School, then highest
    level first);
  - hover a spell for its id, family, power, mana, duration, description, and which spell
    buffing would cast for it.
- **Buff profiles.** The right half of the Spells window builds them:
  - add a buff with **+** or a double-click; one line per spell ladder (adding Strength Other VI
    or Might of the Lugians adds "Strength Self");
  - turn lines on and off, move them up and down (cast order), remove them, add notes;
  - **Add built-in list** starts from the spells buffing casts today for this character;
  - New, Save (to `RynthAi\BuffProfiles\<Name>.json`; rename to save a copy), Delete,
    Refresh, and **Use for buffing** / **Use built-in list**.
- **Loaded Files > Buffs.** A fifth picker (needs RynthCore 2026.10.5.22) chooses the buff
  profile buffing uses, or "Built-in" for the existing list. The choice is saved with the
  settings profile, so each character / settings profile can use a different buff profile.
- `/ra buffprofile` (or `/ra buffprofile list`) shows the profile in use and the saved ones;
  `/ra buffprofile <name>` picks one; `/ra buffprofile none` goes back to the built-in list.

## How buffing uses a profile

- With a profile chosen, its enabled lines replace the built-in buff list, in the profile's
  order. Without one (or if the file can't be read) buffing uses the built-in list as before, and
  says so in chat.
- Each line is a spell ladder ("Strength Self", "Blade Bane", "Blood Drinker Self"). Buffing
  casts the highest level of it you know that your skill allows, exactly as for the built-in
  list (the Buff Min Skill Level tiers still apply).
- Other-target spells and lore names cast the Self ladder of the same spell family; item
  spells keep their Item ladder.
- Server-custom spells without a tier ladder fall back to the best known spell of the same
  ACE spell family, capped by your buffing tier for its school (Self and Item spells win over
  Other ones at the same level).
- The casting skill comes from the catalog school, so profile spells from any school use the
  right skill. Item Enchantment buffs are tracked as item spells (timer from the cast message).
- Saving the profile in use applies within a few seconds; buffing re-reads the file when it
  changes. Switching profiles under Loaded Files applies on the next buff check.

## Files

- `Tools/Generate-SpellCatalog.ps1` (new): builds the slim catalog from ACECustom
  `Reports/SpellCatalog-Full.csv`.
- `Combat/SpellCatalog.tsv` (new, embedded): id, name, level, effect, target, family, power,
  duration, school, mana and description for every spell.
- `Combat/SpellCatalog.cs` (new): catalog loader, lookups, tier stripping and the buffing key
  for a spell.
- `Combat/BuffProfile.cs` (new): the profile model and `BuffProfileStore` (list, load, atomic
  save, delete, id-only entries filled from the catalog, schema check).
- `Combat/BuffManager.BuffProfile.cs` (new): follows the chosen profile file, the profile buff
  list, the school-based casting skill and the family fallback.
- `Combat/BuffManager.cs`: uses the profile list when one is chosen
  (`BuildBuiltInBuffList` is the old list); item spells also recognised from the catalog.
- `Combat/SpellManager.cs`: loads the catalog at login; `CopyKnownSpellIds` for the window.
- `LegacyUi/LegacySpellsUi.cs` (new): the Spells window.
- `RynthAiPlugin.Spells.cs` (new): window setup, pump-thread data for it, `/ra spells`,
  `/ra buffprofile`.
- `RynthAiPlugin.cs`, `RynthAiPlugin.LocalFeatures.cs`: commands, remote commands `spells` and
  `buffprofile`, tick, render and teardown.
- `LegacyUi/LegacyUiSettings.cs`: `CurrentBuffProfilePath`, `BuffProfileIdx`, `ShowSpellsWindow`.
- `LegacyUi/LegacyDashboardRenderer.cs`: the Buffs file list, `buffProfiles` /
  `currentBuffName` / `selectedBuffIdx` in the dashboard snapshot, picker kind 4, settings
  copy on profile load.
- `LegacyUi/RynthAiJsonContext.cs`: `BuffProfile` serialization (NativeAOT).
- `Tools/RynthCore.RynthAiHostTests/Tests/SpellCatalogTests.cs` (new), registered in `Program.cs`.
- `RynthAiVersionCommand.cs`: 0.5.30 -> 0.5.31-legacy-ui.

## Checks

- Spell catalog and buff profile host tests: 10 tests, 77 checks, all passing. They cover:
  - the catalog (schools, levels, targets, name lookup, families);
  - tier stripping and the ladder a spell maps to (Other, lore, Incantation, aura names);
  - profile save / list / load / delete, id-only entries, and refusing a newer schema;
  - buffing with a profile: order kept, disabled and duplicate lines skipped, the catalog school
    picks the skill, the best known level is cast, and the family fallback (capped by tier, none
    while the spellbook is unread);
  - Loaded Files: the list, picking by index, and the snapshot fields the engine reads.
- RynthAi host tests: 461 passed, 5 known failures, 1 failure (the map bake, which needs the
  real dat files on this machine).

- Not yet tried in game.

## Not included

- The Loaded Files Buffs picker and its Spells button are drawn by the engine: they need
  RynthCore 2026.10.5.22. With an older engine use `/ra spells` and `/ra buffprofile`.
- Profiles hold self buffs only (what buffing casts); there are no per-target or fellowship
  buff lists.
