# Merge rynth snapshot 2026.10.13.3, engine API renumbering, RynthJuice crit fix

Needs RynthCore 2026.10.5.55 (plugin API v86). The plugins below must be
installed together with that engine: their API table layout changed (see Why).

## Why

rynth's snapshot 2026.10.13.3 added engine API v84, GetObjectProperties. Our
build already used v84 for ArmConfirmation / GetLastConfirmation and v85 for
GetServerStateJson. The API table is append-only and ordered, so upstream's
numbering stays and ours moves after it:

- v84: GetObjectProperties (upstream)
- v85: ArmConfirmation and GetLastConfirmation (were v84)
- v86: GetServerStateJson (was v85)

A plugin built against the old layout reads these functions from the wrong
slots on the new engine, so every plugin that calls them is rebuilt here:

- RynthAi uses the confirmation pair for crafting.
- RynthAi, RynthOracle, ub-Rythai and the 16 server plugins use the server
  list (ServerStateClient).
