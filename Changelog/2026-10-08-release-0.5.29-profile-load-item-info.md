# RynthAi 0.5.29-legacy-ui - 2026-10-08

Previous release: 0.5.28-legacy-ui.

## Fixed

- **"Describe items when selected" and the Item Info options now stay with the profile.** They
  were written to the character's profile file (`<server>\<character>\<profile>.json`), but
  loading a profile (at login and on a profile switch) copies the file into the live settings
  one field at a time, and that list had no line for the item info options. The defaults stayed
  in memory, and the next autosave wrote them over the file, so the checkbox (in the engine
  Settings and in the RynthAi Item Info window), the click trigger, the per-type filters, the
  hidden fields and ratings, the layout, the chat colours and the prefix all reset on every
  login.
- The same gap dropped these settings on load; they now stay with the profile too:
  - Navigation overlay options (marker colours, waypoint HUD and labels, breadcrumb trail,
    route recording spacing);
  - "Refill empty essences with Encapsulated Spirit" (pets);
  - Ground loot ("Also pick up loose ground items");
  - the Monster Blacklist (Advanced, Combat);
  - ammo rules and the radar window's saved position and size (stored, not yet read back by
    anything else).
- A profile file with `null` item info or nav overlay options loads the defaults, and
  out-of-range hand-edited values are clamped on load (`Sanitize`).

## Files

- `LegacyUi/LegacyDashboardRenderer.cs`: `CopySettings` copies `ItemInfoSettings`,
  `NavOverlay`, `PetAutoRefill`, `EnableGroundLoot`, `MonsterNameBlacklist`, `AmmoRules`,
  `RadarPosX/Y`, `RadarSizeX/Y`. The comment that claimed the source generator guaranteed full
  coverage now points at the test that does.
- `Tools/RynthCore.RynthAiHostTests/Tests/ProfileLoadTests.cs` (new):
  - every serialized `LegacyUiSettings` member set to a non-default value must come through
    `CopySettings`, so a field added later without a copy line fails the run;
  - the item info options survive a save and reload through a profile file, and the reloaded
    profile serializes back unchanged;
  - null item info / nav overlay options load as defaults, and an over-long prefix is trimmed.
- `Tools/RynthCore.RynthAiHostTests/Program.cs`: registers `ProfileLoadTests`.
- `RynthAiVersionCommand.cs`: 0.5.28 -> 0.5.29-legacy-ui.

## Checks

- With the new copy lines removed, the three new tests fail and name the dropped fields; with
  them, all three pass.
- RynthAi host tests: 444 passed, 5 known failures, 1 failure (the map bake, which needs the
  real dat files on this machine).

## Upstream note

`rynth/main` has the same gap for `NavOverlay`, `PetAutoRefill`, `EnableGroundLoot`,
`MonsterNameBlacklist`, `AmmoRules` and the radar placement. Its item info setting
(`ItemInfoOnSelect`) is copied and is not affected.
