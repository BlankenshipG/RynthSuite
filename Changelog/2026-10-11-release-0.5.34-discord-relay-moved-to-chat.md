# RynthAi 0.5.34-legacy-ui: Discord relay moved into Chat

**Date:** 2026-10-11
**Previous release:** 0.5.33-legacy-ui

## Change

The Discord chat relay added in 0.5.33 now lives in RynthCore's chat window, so it is set up in
one place, next to the other chat options:

- Chat > gear menu > Discord (switch, status, **Discord settings…**), or `/rc discord`.
- The engine's version adds per-route chat tabs (any built-in or rule-made tab, not just
  "other lines") and per-route pacing. Settings live in
  `%AppData%\RynthCore\rynthchat_discord.json`. See RynthCore
  `Changelog/2026-10-11-chat-discord-relay.md`.

RynthAi's copy is removed:

- `Plugins/RynthCore.Plugin.RynthAi/Discord/` (relay, settings, window, client, format, DPAPI).
- The relay's wiring in `RynthAiPlugin.LocalFeatures.cs` and `RynthAiPlugin.cs`, and its entry in
  `RynthAiJsonContext`.
- `Tools/RynthCore.RynthAiHostTests/Tests/DiscordRelayTests.cs`. Equivalent and wider checks are
  in RynthCore's `tools/ChatDiscordTests`.
- `/ra discord` now only says where the relay went.

## Upgrading from 0.5.33

The engine imports `RynthAi\discord.json` on its first start without its own settings file. The
import keeps routes, saved webhooks and bot tokens (same DPAPI protection), channels, keywords and
pacing. RynthAi no longer reads or writes that file.

## Verification

- `dotnet build -c Release` of the plugin: 0 warnings, 0 errors.
- Host tests: 470 tests, 464 passed, 5 known failures, 1 failure. The failure is the map bake,
  which needs the real dat files on this machine (same as 0.5.32 and 0.5.33).
