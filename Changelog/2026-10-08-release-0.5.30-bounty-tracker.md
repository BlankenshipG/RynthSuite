# RynthAi 0.5.30-legacy-ui - 2026-10-08

Previous release: 0.5.29-legacy-ui.

## Added

- **Bounties window.** A new ILT Hub window that tracks ACECustom's bounty system. It lists every
  active bounty on the server, wherever you stand:
  - each Vaulted Dungeon (and layer), the all-zones bounty or each zone's, and the region
    bounties;
  - the reward, the kills it takes, and the cooldown between awards (hover the reward);
  - your progress: a kill bar ("34 / 100"), a live countdown while a cooldown runs ("unlocks in
    3m 40s"), or the QB the reward needs;
  - rows whose kills just went up are highlighted for a few seconds;
  - the last bounty message ("Bounty complete! +1 Ascension Coin gained.") and when it arrived.
- Open it with `/ra bounty` (also `/ra bounties`, `/ra bountys`, `/ra hub open bounties`) or
  from the Mini Remote's Options menu (ILT Hub group).
- `/ra bounty refresh` reads the list now; `/ra bounty list` prints the tracked bounties in chat.
- The window has a filter, "Hide QB-locked", and "Closest first" (bounties nearest to an award
  at the top). Under Options: "Update after my kills", the shortest gap between reads
  (default 10 s, at least 5 s) and a periodic re-read (default every 5 min, 0 = off).

## How it tracks

- The server keeps the counts in a server-only property, so the client cannot read them
  directly. The tracker sends `/bounty list` (which reports every bounty with your progress) and
  hides the reply from chat.
- Reads happen only while the window is open:
  - when it opens (if the list is over 30 s old, or you killed something while it was closed);
  - about 2 s after each of your kills, at most once per the configured gap;
  - after a bounty message (award, unlock, "Next bounty ...");
  - on the periodic re-read and on Refresh.
- Cooldowns count down locally; when one ends the bounty shows 0 of N kills, as the server does.
- If you type `/bounty list` or `/bounty` yourself, the reply stays in chat and updates the
  window. A `/bounty` line updates a row only when it can mean just one area (two dungeons that
  pay the same reward are left for the next `/bounty list`).
- On a server without the command ("Unknown command: bounty") automatic reads stop for the
  session; Refresh tries again.
- The last list is saved with the Hub state (`ilt-hub.json`), so the window fills right after
  login. Hub profiles carry the tracker's options but never the bounty progress.

## Files

- `IltHub/IltBountyParse.cs` (new): parses the `/bounty list` and `/bounty` lines, the status
  phrases, the wait text ("1 hr 15 sec") and the bounty chat messages, matching ACECustom
  `BountyManager` / `BountyCommands`.
- `IltHub/IltBounties.cs` (new): the tracker (read scheduling, quiet capture, applying reads)
  and the window body.
- `IltHub/IltHubState.cs`: `IltBountyState` / `IltBountyEntry`, and
  `IltCharacterState.BountiesWindowOpen`.
- `IltHub/IltHubStore.cs`: repairs and clamps the bounty state on load; profiles save and load
  the tracker options only.
- `IltHub/IltSections.cs`: the `Bounties` section (Mini Remote menu, `/ra hub open`).
- `IltHub/IltHubUi.cs`: draws the Bounties window.
- `IltHub/IltHubController.cs`: registers the feature, forwards kills to it, and handles
  `/ra bounty`.
- `RynthAiPlugin.cs`: routes `/ra bounty|bounties|bountys` and the matching remote command to the
  Hub.
- `Diagnostics/RynthLog.cs`: new trace category `IltBounties`.
- `Tools/RynthCore.RynthAiHostTests/Tests/BountyTests.cs` (new), registered in `Program.cs`.
- `RynthAiVersionCommand.cs`: 0.5.29 -> 0.5.30-legacy-ui.

## Checks

- Bounty host tests: 7 tests, 114 checks, all passing. They cover:
  - every line form ACECustom prints (counting, cooldown, QB, layers, N0 numbers, items with
    " - " in the name);
  - full and partial reads, and highlighting after kills and awards;
  - cooldown expiry and save/load;
  - matching `/bounty` lines to the right row;
  - on a fake host: the quiet read on open, a re-read after a kill and after an award, no reads
    while the window is closed, and stopping on "Unknown command".
- RynthAi host tests: 447 passed, 5 known failures, 1 failure (the map bake, which needs the
  real dat files on this machine).

## Not included

- The engine's dashboard Char right-click menu lists the Hub windows from its own table
  (`RynthAiFace.HubSections`), so it does not show Bounties until the engine is updated. The
  Mini Remote menu and the chat commands work now.
