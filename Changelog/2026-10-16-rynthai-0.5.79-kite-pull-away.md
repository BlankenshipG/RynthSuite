## Summary

Combat can **pull a mob away from its lock-spot** before killing it — useful for peeling one add out of a pack. Configurable as a **DEFAULT** option and **per monster rule**.

## How to use

1. **Damage panel** (monster detail) → **Kite**:
   - `Default` — follow the DEFAULT row (on DEFAULT itself, Default means Off)
   - `Off` — fight where the mob stands
   - `PullAway` — tag, run until pulled clear, then kill
2. **Settings → Melee Combat → Pull Away (Kite)**:
   - **Pull Distance (m)** — how far to drag the mob from its lock-spot origin (default 20)
   - **Tag Before Fleeing** — land a hit before running so aggro sticks (default on)
3. External **Monster Editor** has a **Kite** column with the same three values.

## Behaviour

- On lock with PullAway: brief tag window (attacks allowed), then face away and autorun.
- Stops fleeing when the mob has moved Pull Distance metres from its origin (or timeout / no progress).
- Does not switch targets mid-pull; does not drop for “out of range” while kiting; waits for catch-up if the chase stretches.
- Logs `[Kite]` lines for start / flee / done.
