# RynthInventory 0.1.2 - Global Inventory off the bar

Previous: 0.1.1 / ProductVersion 2026.10.16.4.

## Change

Global Inventory no longer asks for its own RynthCore bar button (`BarButton =
false`). It stays in the Scripts menu (`ShowInBar`) and opens from Inventory's
GInv button, Character / Mini Remote menus, or `/ginv`.

- Plugins/RynthCore.Plugin.RynthInventory/RynthInventoryPlugin.cs
