# Changelog — RynthBundle unified installer (2026-04-22)

## Note

The **single Windows installer** that bundles RynthCore (launcher, engine, injector) together with RynthSuite plugins and tools (`LootEditor`, `MonsterEditor`, `RynthCore.Plugin.RynthAi`, etc.) is built from the **RynthCore** repository.

- Script: `RynthCore\Build-Release-All.ps1` or `RynthCore\installer\Build-Installer.ps1`
- Output: `RynthCore\installer\Output\RynthBundle-Setup.exe`
- Requires `RynthCore` and `RynthSuite` as **sibling** directories (or pass `-RynthSuiteRoot` to the build script)

See `RynthCore\BUILD.md` and `RynthCore\Changelog\2026-04-22-rynth-bundle-installer.md` for full details.
